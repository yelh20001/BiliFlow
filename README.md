# BiliFlow

原生 Android B 站客户端 0.15.1。Kotlin、Jetpack Compose、Material 3 与 Media3，最低 Android 8.0（API 26）。

## 界面与浏览

- 直播 / 视频 / 动态 / 我的四个标签，默认进入视频。
- 点击底栏切页时，内容按标签方向滑动并淡入淡出；保存各页的滚动和界面状态，保留重复点击回顶/刷新的行为。
- 跟随系统明暗与 Android 12+ 壁纸取色，另有始终明亮的纯白主题。
- 模糊玻璃顶栏与 56dp 悬浮底栏，底栏取消点击涟漪；顶底栏共用无噪点的 24dp 模糊材质，移除底栏额外阴影与描边。
- 顶栏模糊使用固定位置、稳定尺寸和全分辨率取样，滚动显隐只裁剪输出；顶底栏只应用一次淡入淡出。页面切换的取样层包含不透明底色，减少透明空帧和亮度闪跳。
- 视频、动态顶栏直接显示“为你推荐 / 全站热门 / 关注动态”等实际页面标题，移除顶栏小字副标题。
- 大屏列表按窗口宽度自动显示 2–6 列；手机保留单排/双排设置。平板横屏且窗口宽度达到 840dp 时，详情页左侧播放、右侧浏览简介/推荐/评论，非全屏允许随设备旋转。
- 设置提供持久保存的“界面 HDR 显示”开关，默认关闭。Android 14+ 用增益图呈现顶栏标题、界面图标、选中导航和详情标签、关注/互动/投币/收藏等按钮文字高光；主界面、弹窗和底部面板统一关联开关，可实时切换。支持的屏幕启用 HDR 窗口，Android 15+ 控制界面 HDR 余量；普通正文、背景及禁用控件保留主题和可读性。不支持的屏幕回退普通显示，独立于视频 HDR。
- 视频连续向下加载；下滑隐藏顶栏、底栏，上滑恢复。重复点击视频标签回到顶部，在顶部再次点击刷新。
- 关注动态及选中 UP 主的动态也会随纵向滚动隐藏/恢复顶底栏，切页、切换作者或回到顶部时恢复。
- 原生账号动态：文字、图片、视频、转发与互动计数；直播顶部展示关注的 UP 主正在直播的房间。
- 动态综合流、关注作者的动态和动态详情使用账号授权的安卓 App 接口，按接口游标分页；暂未完整支持的卡片仍保留可见信息。内容和顺序可能因服务端时间、设备及分组不同而变化。
- 部分特殊卡片的复杂交互暂未完整实现；App 授权失效或接口不可用时会显示错误，不悄悄切换成网页动态。
- 动态顶部提供关注头像列表，最近更新动态/视频的 UP 主优先展示，点击切换到该作者的原生动态；可继续加载更多关注。
- 进入某个 UP 主动态后可左右滑动切换相邻 UP 主，仅下方动态内容跟随手势移动；顶部 UP 主列表位于分页容器外，保持固定并可独立横向滚动。点击头像也以分页动画切换，第一项为全部关注。滑动取消不切换请求，页面停稳后才加载目标 UP 主；返回近期访问的作者时恢复动态内容、分页游标和滚动位置。头像顺序在滑动期间保持稳定，已读圆点更新不会跳页。
- 打开关注作者动态并加载成功后同步账号已读进度；服务器确认后清除更新圆点，失败时提供重试。动态页重复点击底栏动态按钮可回顶，在顶部再次点击可刷新。
- 预测返回从松手位置连续位移并淡出，保留播放器直到最后一帧绘制后再移除详情；取消时回弹，避免松手重置页面或提前清空视频。
- Android 12+ 预测返回读取系统报告的四个屏幕圆角，按缩放比例补偿，保持实际显示半径；没有圆角信息时使用直角，不猜测手机型号。

首页使用官方安卓 `app.bilibili.com/x/v2/feed/index`、`mobi_app=android` 与本人授权的 App 令牌。游客状态会明确标注；推荐失败不回退为网页推荐或热门榜。服务端根据时间、设备和实验分组返回内容，不能承诺与另一台官方客户端逐条同序。

视频卡片加载 UP 主真实头像；视频动态直接打开视频，图文动态使用原生详情，转发动态打开原动态。

## 稍后再看

- 长按视频卡片（含动态、UP 主、搜索、相关推荐）或点击视频详情顶栏的时钟按钮，添加到账号稍后再看。
- 我的 → 稍后再看读取账号列表，提供刷新、单项移除、一键清空、一键删除已播放。所有操作均等待服务器确认。
- 播放全部或点击列表项，从所选视频起顺序连播；支持上下个、选择队列项、退出连播，多 P 视频剩余分集播完后进入下一视频，末尾停止。连播切换保留小窗/全屏状态；手动打开其他视频退出原队列。

## 播放器

主页外观设置中提供弹幕样式：透明度、描边粗细、字号、速度、显示区域，以及滚动/顶部/底部弹幕的独立开关。选择会保存并用于视频和直播，也可恢复默认；播放器总开关控制全部类型。

详情页上滑进入全屏时，播放器高度连续展开；竖屏视频保持竖向显示，同样使用高度动画，下滑退出时平滑恢复详情尺寸。

关闭“小窗拖动”时，从小窗或其按钮区域开始滑动可滚动下方页面，小窗保持固定；点击仍用于小窗播放、展开或关闭。开启后，拖动由小窗处理，不带动下层列表。

应用内小窗以面积统一大小，按实际视频比例计算宽高：竖屏较窄较高、横屏较宽较矮、方形居中，三者占用相近面积。屏幕空间不足或视频比例极端时等比缩小。收起时等比缩放并逐渐裁去原播放器黑边；收起、拖动、展开共用同一播放器视图。详情和评论隐藏时保留原来的测量尺寸与组合状态，展开完成后恢复显示，保留评论标签、分页与滚动位置。播放设置新增“小窗拖动”，默认关闭并保存选择；开启后可在屏幕范围内自由拖动，关闭后保留当前位置。

非全屏视频下滑可回到当前浏览页面并进入应用内小窗，小窗避开底栏；切换后台页面、展开后再次下滑及关闭小窗均保留当前页面，不强制跳转视频标签；收起过渡仅让视频画面变黑，使用无回弹曲线衔接手势。评论及楼中楼的图片可点击查看原图，支持缩放与多图切换；评论数据受 B 站接口可用性限制。

评论图片与表情支持 GIF 动画（Android 9+ 同时支持动态 WebP）；大图在未放大时单指左右滑动切换，放大后单指移动图片。多层相关推荐下拉进入小窗时隐藏上一层详情并保留返回栈，小窗展开后仍能逐级返回。

- DASH 视频与音频、自适应或指定清晰度；设置中保存新视频的首选清晰度。实际选项根据片源与账号权限开放。
- 支持 HDR / 杜比视界画质选项，HDR 片源使用 SurfaceView 输出。按当前显示模式、具体片源与 Media3 解码能力选择路径：原生杜比设备交给播放器检查片源，普通 HDR 设备可播放兼容的 HEVC Main10 基础层，不再只因缺少屏幕杜比标记而提前降画质。兼容播放会明确提示；不兼容的 Dolby Profile 5 不强行改写为 HEVC。真正解码失败时保留进度切换兼容画质，网络/解析错误不再永久关闭 HDR，手动切换画质可重新尝试。播放控件根据实际色彩传递信息显示 HDR 状态。真实杜比输出、HDR 色彩、峰值亮度与厂商切换效果仍需对应真机确认。
- 修复特定 HEVC 初始化信息的空 VPS 视图列表越界，保留原始 HDR/色彩信息；构建兼容补丁说明见 `app/compat/README.md`，实测与限制见 `artifacts/V15-VALIDATION.md`。
- 画质回退等播放提示使用 24dp 圆角的模糊玻璃材质、固定深色蒙层与白色文字，较底部抬高 36dp；明暗主题共用同一材质配色，透出的背景会随页面变化。
- 设置提供“画质变更提醒”，默认关闭并保存选择；关闭后仍正常调整可用画质，只隐藏打开视频时的画质提示，操作失败等其他提示保留。
- 首页及相关推荐共用封面到播放器的过渡；使用实际测量的位置，不使用整页视频截图。目标播放器保持黑底，不再叠放一张相同封面；移动封面抵达后再渐显播放画面。
- 播放器下方提供“简介与推荐”和“评论”两个可横滑页面；相关推荐使用官方单视频关联接口。连续打开相关视频可逐级返回，恢复先前页面与进度；右上角提供一键返回视频主页。
- 作者头像、名字、粉丝数、发布时间；关注、点赞、投币和账号收藏夹选择，支持新建收藏夹。账号写入在用户明确操作后提交，失败不会假装成功。
- 点赞/投币/收藏未操作时为空心图标，操作后为实心与强调色。点击立即更新并阻止重复请求，失败回滚；旧查询不会覆盖新的操作。兼容数字/布尔互动状态与重复点赞的幂等确认。
- 双击左右侧后退/前进 10 秒，双击中间播放/暂停；横向拖动定位，上滑全屏、全屏下滑退出，长按临时 2 倍速，松开恢复。
- 上下拖动时视频画面同步位移、缩放、圆角变化，松手后回弹并衔接全屏尺寸过渡；直播共用同一手势实现。
- 退出全屏、切清晰度和进入画中画复用播放器；暂停时换清晰度仍保持暂停。
- 点按呼出的播放器控件统一以 180ms 淡入淡出。非全屏保留系统状态栏、导航栏的稳定尺寸，全屏尺寸变化使用动画，不因系统栏显隐再次挤动内容。
- 进度条采用 20dp 高的当前位置竖条，布局高度 32dp 并保留底部间距，横竖屏均保持在视频内。
- 返回桌面时使用 Android 原生画中画。Android 12+ 自动进入，并让系统在小窗缩放时衔接尺寸变化前后的画面。画中画大小由系统管理，设置可关闭自动小窗。
- Android 15+ 在小窗动画开始回调中提前隐藏详情、弹幕及控件；较旧系统在离开应用时预先隐藏。缩放中固定视频源矩形，小窗布局立即移除顶栏占位，避免点赞/投币区域或顶栏混入视频。
- 按视频和分 P 保存播放进度，定期保存并在暂停、定位和离开时保存；再次打开恢复，接近末尾时重新播放。
- 详情与全屏弹幕，支持开关；评论页面直接连续分页，支持下拉刷新、刷新按钮和楼中楼回复。特殊高级弹幕暂不渲染，暂不支持发送弹幕、发布评论。

直播间使用原生 Media3 HLS 播放，提供主播资料、房间信息、清晰度、实时聊天、全屏手势与系统小窗。进入时读取最近聊天，随后通过带账号与房间授权的 WSS 长连接接收真实弹幕；普通与全屏播放均显示弹幕，30 秒心跳、断线退避重连、队列有上限。关闭弹幕、暂停、进入小窗和离开直播间时释放连接，恢复播放时重连。暂不包含发送消息、礼物或连麦。直播落后于有效播放窗口时自动重定位，暂停后恢复回到直播位置。

官方登录备用入口使用内置官方网页。尚未实现离线下载。

## 新安卓设备的显示与播放

- 点播使用 TextureView，保持详情页和应用内小窗切换时的画面位置一致；Android 14+ 直播使用 SurfaceView，较旧系统使用 TextureView。视频通过无缝帧率匹配交给系统调度。
- 实际查询设备的硬件解码能力，在支持的编码中选择较低带宽的同画质视频；不按手机型号猜测 AV1/HEVC 支持。解析或解码不兼容时回退 AVC，保留进度。
- 编码能力查询与 MPD 构建移出界面线程；无视频时停止进度轮询，暂停时降低轮询频率并停止周期性写入进度。
- 弹幕只遍历当前时间窗口，逐屏幕 vsync 绘制，移除旧 60fps 限制；弹幕开启并播放时请求 120Hz，暂停、关闭弹幕、进入小窗或离开播放页时恢复系统刷新策略。无弹幕时降低唤醒频率。实际刷新率仍受面板能力与系统策略约束。
- 仅当前视频创建播放 Surface，返回栈中的上一页用静态封面；缓存有上限，避免为连续推荐累积解码器或整页截图。
- 系统明暗切换无需重建 Activity；横屏控件避开挖孔区域，布局使用实际尺寸与系统栏 inset。

这些是面向 S25+ / One UI 9 / Android 17 使用场景的兼容路径和负担削减，未连接该手机，未测量它的真实功耗、温度或帧率。QHD 尺寸模拟与 Android 15 功能验证不能代替三星真机验收。[Surface 输出选择](https://developer.android.com/media/media3/ui/surface)、[Media3 功耗说明](https://developer.android.com/media/media3/exoplayer/battery-consumption)。

## 登录与数据

支持官方扫码授权；也可通过内置官方短信/密码登录页后确认 App 授权。扫码后验证账号再切换为账号安卓推荐。Cookie 与 App 令牌使用 Android Keystore 的 AES-GCM 密钥加密保存在应用私有目录，禁止备份。退出登录清除会话；本地收藏、浏览历史、播放进度保留在当前安装内。


`device-probe` 是单独的测试 APK，供快速读取无障碍树、注入手势和采样预测返回画面；不包含在客户端 APK 中。测试需要已登录的专用模拟器，使用上面的 0.5/0.6 脚本，不投币、不改点赞、收藏或关注、不清除授权。截图仅保存在忽略的 `.tools/`，结果 JSON 不记录账号信息。脚本会改变本地清晰度、进度及浏览状态；旧版脚本仅供历史验证参考。

0.5 脚本全部为账号只读检查。导航动画的中间帧检查依赖 Debug 版的逐帧回调日志；读取整个无障碍树会阻塞界面线程，因此不在封面移动过程中反复读取完整树。发行版移除该日志。脚本会切换模拟器明暗、首选清晰度和 QHD 尺寸；尺寸测试在 finally 恢复原分辨率。发行包可额外运行 `v5-device-test.py release` 验证覆盖安装后的账号、入栈/返回与非 debuggable 标记，运行 `v5-device-test.py live` 验证原生直播。

0.5 的 `palette` 阶段验证旧版不透明背景，不适用于 0.6 的半透明模糊材质；本版使用 `v6-device-test.py notice` 检查浅深色中的提示，临时延长系统无障碍提示超时以便截图，finally 恢复设置。`fade` 暂停视频后采样透明度中间画面，先采集再压缩 PNG，避免压缩耗时漏掉短动画。实时弹幕检查使用接收计数、Canvas、心跳和生命周期状态，不发送任何直播消息。

0.7 默认关闭画质提示，使用 `v7-device-test.py` 验证开关及其持久化；旧 `v6-device-test.py notice` 需要事先开启该选项。120Hz 请求与恢复可在 Activity dump 中看到，60Hz 模拟器不能证明三星手机实际达到 120fps。

本机模拟器通过系统代理 `10.0.2.2:7899` 访问网络；客户端代码没有硬编码代理。其他环境应按自身网络调整或清除模拟器代理。旧版 `playback-test.py` 的后台暂停断言不适用于默认开启画中画的版本，0.3 评论测试的“查看全部评论”断言不适用于 0.4 连续评论流。

验收证据与限制见 `artifacts/VALIDATION.md`。模拟器测试不能代替真实手机的帧率、不同厂商的画中画动画及 Android 8–14 兼容验证。
